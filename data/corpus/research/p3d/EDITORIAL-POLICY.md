# P3D editorial and provenance policy v1

## Statements

- Canonical identity is never inferred from publication wording; P3C identity remains authoritative.
- Final statements start from the 719 frozen, visually checked official transcriptions already in the corpus research layer.
- Exact same-Version MathNet statements may seed shortlist publication files when their source link is frozen exact/equivalent.
- Normalize whitespace, Markdown, LaTeX delimiters and stable asset keys only. Any wording change that can affect mathematical meaning requires an explicit reviewed record.
- Production selection points to a local curated file. Research/source-field references remain provenance, not public runtime dependencies.
- Never silently synthesize an unrecovered shortlist statement.

## Solutions

- Goal: one reviewed primary English solution per public Version where defensibly obtainable; alternatives only when materially useful.
- Final-problem authority preference: official Baltic Way solution material > organizer/reputable archive > verified curated adaptation; MathNet/AI-MO are cross-check/transcription aids.
- A raw upstream solution is never `verified` merely because a file exists.
- Review must cover mathematical correctness, completeness, exact Version compatibility, notation/formatting, hidden image dependencies and any adaptations.
- `unresolved` means research/review is incomplete. `unavailable` is reserved for a positive conclusion that no publishable solution is available under the project policy.

## Assets

- Asset keys in Markdown are logical (`figure:1`, etc.), not filenames or remote URLs.
- Every selected asset is a local curated file with SHA-256, owner (statement/solution), provenance, alt text and presentation mode.
- Required-for-meaning statement figures block publication if unresolved.
- Prefer faithful extraction/redraw of official figures over low-quality source rasters where practical; record that a redraw is derivative of the official figure.

## Topics

- Primary domain: exactly one of Algebra (A), Combinatorics (C), Geometry (G), Number Theory (N).
- Finals inherit/confirm the P3C frozen domain unless review establishes a corpus error.
- Public shortlist-only candidates without domain require explicit classification.
- Raw MathNet topic strings are non-canonical seed evidence.
- Prefer zero to three controlled subtopics; avoid tag inflation.

## Rights/materialization

- Provenance and authority do not automatically grant permission to bulk-copy remote content into a deliverable.
- This freeze only materializes statement bytes already supplied inside the user's repo/source cache.
- Remote secondary statement pages are represented by locators until a suitable local/source copy is supplied or otherwise appropriately handled.
