# Curated publication files

These files are local publication material selected by canonical `content-selections.jsonl` and `asset-bindings.jsonl` records. Runtime website code may consume selected curated files, but must not compile content directly from `data/corpus/research/`, Parquet shards, source caches, or remote URLs.

P3D local-evidence curation intentionally remains incomplete where source bytes or required figures were not locally available. Exact gaps are frozen under `data/corpus/research/p3d/`.
