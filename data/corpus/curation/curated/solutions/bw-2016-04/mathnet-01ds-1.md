Let
$$
w(x) = (x-a)(x-b)(x-c)(x-d) = x^4 + A x^3 + B x^2 + C x + D.
$$
It is clear that $w(a) = w(b) = w(c) = w(d) = 0$. By adding these values we get
$$
\begin{aligned}
w(a) + w(b) + w(c) + w(d) = a^4 + b^4 + c^4 + d^4 \\
\quad + A(a^3 + b^3 + c^3 + d^3) + B(a^2 + b^2 + c^2 + d^2) \\
\quad + C(a + b + c + d) + 4D = 0.
\end{aligned}
$$
Hence
$$
\begin{aligned}
a^4 + b^4 + c^4 + d^4 + 4D &= -A(a^3 + b^3 + c^3 + d^3) \\
&\quad - B(a^2 + b^2 + c^2 + d^2) \\
&\quad - C(a + b + c + d).
\end{aligned}\quad (5)
$$
Using Vieta's formulas we can see that $D = abcd$ and $-A = a + b + c + d$, and therefore right side of (5) is divisible by $n$, and so is left side.
